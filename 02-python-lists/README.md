# Day 02 — Python Lists

This exercise covers Python lists and some built-in functions used to work with collections of values.

## Topics Covered

- Creating a list
- Accessing elements using indexes
- Finding the maximum and minimum values
- Adding elements using `append()`
- Counting elements using `len()`

## Practice

The Python file contains a list of student marks. It displays the marks, finds the highest and lowest values, adds a new mark, and counts the elements in the list.
